# Decision Tree Classifier for Bank Marketing Dataset

## Objective
Build a Decision Tree Classifier to predict whether a customer will purchase a product or service based on demographic and behavioral data.

## Dataset
Bank Marketing Dataset

## Tools Used
- Python
- Pandas
- Scikit-learn
- VS Code

## Steps
1. Loaded the dataset.
2. Converted categorical data into numerical values.
3. Split data into training and testing sets.
4. Trained a Decision Tree Classifier.
5. Evaluated the model using accuracy.

## Result
The Decision Tree model successfully predicted customer purchase behavior and achieved good accuracy on the test data.
